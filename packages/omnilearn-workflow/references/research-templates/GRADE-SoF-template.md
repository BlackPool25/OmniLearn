# GRADE Summary of Findings — Template (per outcome)

To grade an outcome, assess the body of evidence — not a single source.

## Outcome: {outcome name}

| Domain | Judgment | Rationale |
|--------|----------|-----------|
| Risk of bias | No serious / Serious / Very serious | RoB 2 / ROBINS-I / tech transparency checklist |
| Inconsistency | No serious / Serious | I² or qualitative heterogeneity |
| Indirectness | No serious / Serious | Population/intervention vs target |
| Imprecision | No serious / Serious | Sample/observation count, CI width |
| Publication bias | Undetected / Suspected | Search completeness, funnel, grey lit |
| Large effect | No / Yes (+1) | Upgrade if large + consistent |
| Dose-response | No / Yes (+1) | Upgrade if gradient |
| Residual confounding | No / Yes (+1) | Upgrade if effect despite bias toward null |

**Certainty:** High / Moderate / Low / Very Low
**Footnotes:** Downgrade/upgrade reasons per domain.
**Importance:** Critical / Important / Not important

Copy per outcome into `04-synthesis/SoF-{outcome}.md`.
